Employee Leave & Attendance System

A simple Human Resource (HR) Mini Project that manages employee attendance, leave requests, and basic employee data, built with a frontend and backend.
This system helps organizations track attendance & leave for employees efficiently.

🚀 Project Overview

This project is an Employee Leave & Attendance System (HR mini project) designed to:

Register and manage employees

Record daily attendance

Submit and approve leave requests

Provide dashboard/UI for employees and admin

Track leave history

It comes with separate frontend and backend folders for UI and server logic.

🧠 Features

✔️ Employee Signup / Login
✔️ Mark Daily Attendance
✔️ Apply for Leave
✔️ View Leave Status
✔️ Admin Dashboard to Manage Attendance & Leaves
✔️ Frontend + Backend separation for clarity
